# Words we use in the GUI

Assume the reader has not heard NAS jargon.

| We say | Means |
| --- | --- |
| Pool | The bucket where files live |
| Share | The name a PC uses to open that bucket. Same name at home and away |
| On another computer | Files stay on Proxmox or TrueNAS; keel does not wipe them |
| Disks in this machine | Files would live on drives in the keel box |
| Look around | Knock on one computer’s well-known doors (Proxmox, website, Windows folders). Not a scan of the whole house |
| Open / closed | Like a computer: the app is on disk; running only when you need it |
| Away | Same files, not on the house Wi‑Fi. Tailscale (or whatever overlay we ship) is that path |

Short forms in the GUI (`lsblk`, RSS, …) are dotted links to Guide `#ids`. See terms.js. Do not dump jargon without a Guide entry.
