Settings

Updates come from your existing GitHub repository, github.com/robbykube/keel. That repository is private, so this computer needs your permission to see it. Connect GitHub on your phone or this PC. You do not need a second repository. The sign-in stays on this computer.

On your phone or another computer, open github.com/login/device and enter that code. Then allow Keel to read releases.

Paste a token instead

A GitHub token with read access to robbykube/keel also works. The page never shows it again.

The app id is public. It is only needed if Connect GitHub does not start. That GitHub App is a login on the repository you already have, not a new project. Tick Enable Device Flow, turn off expiring tokens, Contents read, and allow it on robbykube/keel.

Update Keel from a GitHub release, not from every change on the repository. If the new version does not start, the previous one comes back.
