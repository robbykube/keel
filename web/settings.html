Settings

Updates come from your existing GitHub repository, github.com/robbykube/keel. That repository is private, so this computer needs your permission to see it. Connect GitHub on your phone or this PC. You do not need a second repository. The sign-in stays on this computer.

People

Each person signs in with a name and password. The page then knows who it was. Adding an existing name replaces that password. Opening folders in File Explorer still uses the name on the Files page.
