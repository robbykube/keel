Shares

A share is the name File Explorer uses to open the files. Same name at home and away.

How do I open this from Windows?

On the Keel computer, File Explorer can open the folder like a network drive. Paste the address (it starts with two backslashes). For this house network the name is keel and the password is keel. That is open on purpose until Keel has real sign-in. Do not put this on the public internet.
