Pools

A pool is the bucket the files live in. One bucket now. You pick whose disks hold it.

What is a pool?

Think of a big box of files. keel does not care yet which brand of box — only where the box is.

On another computer means: your Proxmox or TrueNAS machine already has the files. keel just uses that folder. Nothing is copied. Nothing is wiped. Pick this while rok stays as it is.

Disks in this machine means: keel would use hard drives plugged into the keel box. We are not doing that on this Windows PC. You can still name the intent.

The address is “how to find that folder on the other computer.” You will get that from the other machine’s share settings. You do not need to know the short names for those sharing methods.

Did I reach Proxmox?

Look around + Sign in on the left is how keel talks to Proxmox. Success looks like: status says “signed in to proxmox”, and a list appears (Node rok, local, vm-data, …). The password is not kept, so you sign in again next time. Remembered names (below Look around) mean we have seen that computer before.

A row in the table on the right is a plan of which bucket keel should use. It now survives a restart. This Windows copy still does not mount the disk as a drive letter. To actually see names of files, Sign in on the left, then List files. Family files are in OpenCloud, not on Proxmox local.

You still open Proxmox in the browser the usual way. keel does not replace that screen.

Sign in on this page. Do not paste the password into chat. keel keeps the name, not the password. The Proxmox session stays in memory so you can list files until keel restarts.

Check files — OpenCloud name and password, not Proxmox. Paste the files website if List files did not find a door.
