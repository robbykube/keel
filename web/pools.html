Pools

A pool is where the files are stored. Keep files that already exist, or use disks in this machine.

What is a pool?

A pool is the files keel should use. keel does not care yet which brand of system holds them — only where they are.

On another computer means the files already live there (your Proxmox or TrueNAS machine, in this house). keel uses that folder. Nothing is copied. Nothing is wiped. Sign in on the left so keel can read the names that computer already uses. It does not invent them.

Disks in this machine means keel would use hard drives plugged into the keel box. We are not doing that on this Windows PC. You can still name the intent.

Disks in this machine means the hard drives plugged into this keel computer. They are listed on the Dashboard.

Most people only need “on another computer” at install, to keep personal files. Day to day they use a share name, not Proxmox disk names. This lab still needs the Proxmox list while rok holds the files.

Did I reach Proxmox?

Look around + Sign in on the left is how keel talks to that computer. After sign-in, keel reads the names Proxmox already has, then marks each row Use this or Leave this. Shared folders and the files app are use. Installer disks and disks for other programs are leave. The password is not kept, so you sign in again next time.

A row in the table on the right is a plan of which files keel should use. It survives a restart. This Windows copy still does not attach those files as a drive letter. To see file names, Sign in, then List files.

If you already know those names, tick Show the names that computer uses. Rows still say Use this or Leave this. Default is the plain heading.

Sign in on this page. Do not paste the password into chat. keel keeps the name, not the password. The Proxmox session stays in memory so you can list files until keel restarts.
