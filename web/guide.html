What keel is

A small NAS: a computer whose job is storing files and handing them to phones and PCs. You use it in a browser. It is not Proxmox (that runs other computers) and not a second OpenCloud. OpenCloud on rok can keep serving files; keel can use that same folder.

This Windows copy

You are looking at the control panel we are building. The real keel OS will run on Linux later. Disks here are fake. Pools you add are a saved plan, not a real mount yet.

What to do now: click the pages, leave ideas in Notes, maybe add a pool as “on another computer.” Do not wipe rok. Do not expect this PC to serve family files yet.

This keel computer

You are looking at the keel computer itself. The disks on the Dashboard are really plugged into this machine, and a share you publish here can be opened from other computers in the house.

What to do now: group disks into a pool, publish a share, then open the address on the Dashboard from another computer to check it works from there too.

Dashboard is health plus this machine’s disk list. Disks is not a separate place — that extra link is gone so the two do not look like twins.

Try Keel from USB

The safest first appliance test uses a spare computer and a USB stick. Windows writes the Keel image to the stick. The spare computer boots from it, while your Windows PC opens Keel in a browser on the same local network.

Try mode does not install anything. It runs Keel temporarily so you can check the screen, network, and hardware. When you are ready, choose Install, select the internal disk by its name and size, read the warning, and confirm. Keel must never guess which disk you meant.

Keel can work without internet during the USB test. It only needs the local network for Windows to open the GUI. Internet is needed later to check GitHub for a signed update, or to join a Headscale server that is somewhere else. An update keeps the previous version and puts it back if the new one does not start.

You cannot run the USB as a normal Windows app while Windows is using that computer. To test it on the same PC, reboot and choose the USB, or run the image inside a disposable VM. The Windows installer will explain each choice in simple words.

Open files from Windows

When Keel is running on a Linux computer on this house network, File Explorer can open a folder on that computer. On Shares, copy the address that starts with two backslashes. For now the name is keel and the password is keel. That is open on the house network on purpose. It is not safe on the public internet.

On USB try-mode that folder is temporary. Files you copy there are gone when you shut the computer down. This Windows copy of the control panel cannot serve folders; only the Linux Keel computer can.

Notes

A scratch pad in the app, like Notes in the AI Suite. For things you want to add to keel. It is saved on this PC so a restart does not eat it. It is not the family photo library.

Finding it at home

Open it by address, like a website on your home network. The folder on a PC looks like a network drive. Fancy auto-discovery is extra.

rok already has a private remote path (the overlay), home DNS names, and a website in front. Those stay on rok until keel has its own box.

Away from home

The same files should open when you are away from home: same share name, not a second copy in the cloud. The overlay is how that works. The box stays on so the path stays up. We do not put family files on the public internet.

At home you use the house address. Away you use the overlay address. Samba must accept both. If we stop Samba to save power, opening a file from away has to start it — you should not hunt the catalog first.

Keeping files you already have

keel does not invent names like the ones Proxmox uses. After you sign in, it reads the names that computer already has, then marks each row Use this or Leave this.

Use this: a folder a PC can already open, or a files app (if that computer named it something like OpenCloud). Leave this: installer files, or disks that belong to other programs.

This house still needs that list while files live on rok. For a new keel box, most people only do this at install — so personal files stay where they are. After that, they use a share name. They do not live in Proxmox names.

If you already know the names on that computer, you can show them. Tick “Show the names that computer uses” on Pools. Use this / Leave this stays. Default is the plain heading.

Look around

On Pools, type the name or number of that computer — whatever you already use in the browser. keel checks a few well-known services: Proxmox, websites, shared folders. It does not scan every machine on the house network. An open website is not yet a folder of files.

You can sign in on that page so keel can list what is there. The password is typed into keel on this PC. Do not paste it into chat. Every name you type is kept until you delete it. keel does not keep the password. The Proxmox session stays in memory until keel restarts, so you can list files without signing in on every click.

The raw Proxmox port can stay closed when a locked website sits in front. Sign-in still talks to that website.

Check files

Family files live in the files app (OpenCloud on rok), not on disks that belong to other programs. After you sign in to Proxmox, Pools says Use this or Leave this. Listing the files app needs that app’s name and password — not the Proxmox one. You can also paste the files website you already open. Listing is read-only. Open the files app to change anything.

List files on installer disks or disks for other programs shows installers and program disks. That is how you check what that computer is storing. It is not the photo library.

Idle

keel works like an OS. The computer stays on. Apps stay closed until you open them. Idle keeps Tailscale so you can open files and the GUI when you are not at home. We do not sleep the whole Proxmox machine.

What ships

The OS comes with the same jobs as your rok list (VPN, passwords, files, photos, and so on). Installed does not mean running. Open the one you need; the rest can stay off.

Pools and shares

Linux Keel starts with a share named files so a PC can open a folder without extra setup. Add more names on Shares after you have a pool. Prefer “on another computer” so rok is left alone.

Repair

If something is wrong, Repair says it in a sentence. Fix is a safe button, not a settings hunt.
