Guide

This page lives in the app so you never have to hunt a wiki.

Words

Short names in the app look like this and jump here.

Pool
The bucket where files live.
Share
The name your computer uses to open that bucket (a network folder). Same name at home and away.
lsblk
Linux’s list of disks in the machine. This Windows copy fakes that list.
RSS
How much memory the keel program is using right now. Smaller is better.
API
The app asking itself for numbers (disks, health). The timing on the dashboard is how fast that answer came back.
SMART
The disk reporting if it feels healthy. Not on this Windows copy yet.
LXC
A small computer-inside-a-computer on Proxmox. Your rok list is these. keel’s OS uses normal programs instead.
Tailscale
The overlay we use today: a private path so phones and laptops open the same shares when you are not on home Wi‑Fi. Idle keeps it on. If we switch brands, the job stays: files work away from the computer.
Away
Not on the house network. You still open the share; the overlay (Tailscale today) is the road.
OpenCloud
The files app already running on rok. keel does not replace it there.
Proxmox
The system on rok that runs those small computers. We do not wipe it.
TrueNAS
Another common file-box system. Files can stay there; keel can use that folder.
systemctl
Linux’s on/off switch for programs. Repair buttons will use this on a real keel box.
nft
Linux’s door lock for the network (which ports are open). Not this Windows PC.

What keel is

A small NAS: a computer whose job is storing files and handing them to phones and PCs. You use it in a browser. It is not Proxmox (that runs other computers) and not a second OpenCloud. OpenCloud on rok can keep serving files; keel can use that same bucket.

This Windows copy

You are looking at the control panel we are building. The real keel OS will run on Linux later. Disks here are fake. Pools you add are a saved plan, not a real mount yet.

What to do now: click the pages, leave ideas in Notes, maybe add a pool as “on another computer.” Do not wipe rok. Do not expect this PC to serve family files yet.

Dashboard is health plus this machine’s disk list. Disks is not a separate place — that extra link is gone so the two do not look like twins.

Notes

A scratch pad in the app, like Notes in the AI Suite. For things you want to add to keel. It is saved on this PC so a restart does not eat it. It is not the family photo library.

Finding it at home

Open it by address, like a website on your home network. The folder on a PC looks like a network drive. Fancy auto-discovery is extra.

rok already has a VPN (Tailscale), home DNS names, and a web front door. Those stay on rok until keel has its own box.

Away from home

Files should work on the train the same way they work in the kitchen: same share name, not a second copy in the cloud. Tailscale (or whatever overlay we ship) is that path. The box stays on so the path stays up. We do not punch family files through the public internet.

At home you use the house address. Away you use the overlay address. The share is one door. Samba must listen on that overlay; if we park Samba to save watts, opening a file from away has to start it — you should not hunt the catalog first.

Look around

On Pools, type the name or number of that computer — whatever you already use in the browser. keel knocks on a few well-known doors: Proxmox, websites, Windows folders, NFS. It does not scan every machine on the house network. An open door is not yet a pool.

You can sign in on that page so keel can list storage. The password is typed into keel on this PC. Do not paste it into chat. Every name you type is kept until you delete it. keel does not keep the password. The Proxmox session stays in memory until keel restarts, so you can list files without signing in on every click.

Port 8006 can stay quiet when a front door (the locked website on 443) is in front of Proxmox. Sign-in still talks to that website.

Most Proxmox storage is disks for virtual machines, not a folder a laptop opens. Only use a row if it is already a shared folder. Do not point keel at local on rok.

Check files

Family files live in the files app (OpenCloud on rok), not on Proxmox’s own disks. After you sign in to Proxmox, Pools can find that app and list names. That needs the files app name and password — not the Proxmox one. You can also paste the files website you already open. Listing is read-only. Open the files app to change anything.

List files on local / vm-data shows ISOs and guest disks. That is how you check what Proxmox is storing. It is not the photo library.

Idle

keel works like an OS. The computer stays on. Apps stay closed until you open them. Idle keeps Tailscale so you can open files and the GUI when you are not at home. We do not sleep the whole Proxmox machine.

What ships

The OS comes with the same jobs as your rok list (VPN, passwords, files, photos, and so on). Installed does not mean running. Open the one you need; the rest can stay off.

Pools and shares

First add a pool (the bucket). Prefer “on another computer” so rok is left alone. Then add a share (the door).

Repair

If something is wrong, Repair says it in a sentence. Fix is a safe button, not a settings hunt.
