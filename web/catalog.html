Why this list

keel works like an OS: the programs are on the disk. You open one when you need it. Nothing has to be on all the time. Idle keeps Tailscale so files and the GUI still work when you are not at home. Active can start the usual files/DNS/vault/proxy set and still leave the quiet ones closed until something asks. These become units on keel Linux, not Proxmox LXCs.
